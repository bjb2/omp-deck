# Copywriting

Use when the text has a job — move a reader toward an action. Landing pages, hero sections, CTAs, email subject lines, ad copy, product naming, taglines, value propositions.

## Triggers

- "Write a hero section for X"
- "Improve this CTA"
- "Subject line variants"
- "Rewrite this landing page headline"
- "Draft a value proposition"

## Frameworks (pick one, not all)

- **AIDA** — Attention → Interest → Desire → Action. Default for landing pages and sales pages.
- **PAS** — Problem → Agitate → Solution. Default for ads, cold email, pain-led messaging.
- **BAB** — Before → After → Bridge. Default for product pages where the contrast is the story.
- **4 Ps** — Promise → Picture → Proof → Push. Default for long-form sales letters.

## Principles

1. **Specificity > adjectives.** "Saves 4 hours/week" beats "Saves time". Numbers, named tools, concrete outcomes.
2. **Write the headline last.** Draft the body first, then promote the most concrete promise to the top.
3. **One CTA per section.** Multiple CTAs split attention. If primary + secondary, name them ("Start free trial" + "See pricing").
4. **Mirror the reader's words.** Pull phrasing from how the audience describes their problem — reviews, support tickets, sales calls.
5. **Active voice, present tense, second person.** "You get X" not "X is provided". Save passive for genuine ambiguity.
6. **Cut what doesn't earn its place.** Read aloud; anything you'd skip while speaking goes.

## Landing-page structure

1. Hero: headline (promise) + subhead (who / what it replaces) + primary CTA + secondary CTA
2. Social proof: logos, numbers, named customers — pick the most credible form, not all
3. Problem: name the pain in the reader's words
4. Solution: 3–4 features mapped to outcomes, not capability bullets
5. How it works: 3 steps, concrete verbs
6. Objections: pricing, onboarding, switching cost, lock-in
7. Final CTA: restate the promise + close

## Email subjects

- 6–10 words, lowercase or sentence case, no period
- Specific > clever ("v2.3 ships Friday" beats "Big news!")
- A/B by changing one element at a time: number, name, verb, or emoji

## Pairing

- Landing page audit → for each section, ask "what action does this drive?" If none, rewrite.
- CTA redesign → list 5 verbs the user could do; pick the most concrete.
- Value-prop clarification → answer "what does this let the user do, that they couldn't before, in a specific measurable way?" Vague answer = rewrite.
